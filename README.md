# IPL Data Analytics Dashboard using Python

A sports analytics project built using Python and Google Colab to analyze IPL match data and visualize team and player performance.

## Project Overview

This project analyzes IPL match data using:

- Pandas
- Matplotlib
- Seaborn
- Google Colab

The dashboard helps understand:

- Team performance
- Match winners
- Toss decisions
- Player of the Match statistics
- Venue analysis
- Winning percentages

## Features

✅ Matches won per team analysis  
✅ Most successful team visualization  
✅ Toss decision analysis (Bat/Field)  
✅ Top Player of the Match winners  
✅ Venue analysis  
✅ Team performance dashboard  
✅ Winning percentage calculation  
✅ Full 2×2 analytics dashboard

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The project uses:

- `matches.csv`
- `deliveries.csv`

containing IPL match and ball-by-ball data.

## Project Output

The dashboard generates multiple visualizations including:

1. Team win analysis  
2. Toss decision pie chart  
3. Top player performance  
4. Venue analysis  
5. Winning percentage chart  
6. Full analytics dashboard

## How to Run

1. Open Google Colab
2. Upload `matches.csv` and `deliveries.csv`
3. Run all cells in the notebook
4. View generated charts and dashboard
